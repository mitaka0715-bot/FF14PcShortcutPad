FF14 PC Shortcut Pad

概要
XIVLauncher / Dalamud 用のゲーム内ショートカットPadです。
外部EXEではなく、FF14内のDalamud UIとして表示します。

起動コマンド
/ffpcpad

設定コマンド
/ffpcpad config

主な機能
- 4x4 のアイコンボタン
- 10ページ保存
- ページ送り/戻りショートカットを設定可能
- 各ボタンにショートカットキー、表示テキスト、実行コマンド、アイコンを設定可能
- FF14コマンドを実行可能
- 他Dalamudプラグインのコマンドを呼び出し可能
- / で始まらない行は通常チャット本文として /say 送信
- PNG/JPG/WEBPなどの画像をアイコンとして選択可能
- アイコンサイズ、ボタン間隔、背景アルファを調整可能

便利な使い方
ボタンの実行コマンドに、FF14コマンドや他プラグインのコマンドをそのまま入れられます。

例
/ac スプリント
/fc こんにちは
/sh よろしくお願いします
/p よろしくお願いします
/cammy
/vbm

注意
- /p または /party は、PT参加中ならPTチャットに送信できます。
- PT未参加時は、手入力時と同じエラー表示にならない場合があります。
- / で始まらない文章は /say として送信します。
- このプラグイン本体にはFF14公式アイコン画像を同梱していません。別途アイコン抽出プラグインなどで icons フォルダを作成し、設定画面の「アイコンフォルダ」に指定してください。
- FF14、XIVLauncher、Dalamudの利用規約やプラグイン利用ポリシーを確認し、自己責任で使用してください。
