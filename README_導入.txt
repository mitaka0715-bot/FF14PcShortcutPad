FF14 PC Shortcut Pad

概要
XIVLauncher / Dalamud 用のゲーム内ショートカットパッドです。
外部EXEではなく、FF14内のDalamud UIとして表示します。

起動コマンド
/ffpcpad

設定コマンド
/ffpcpad config

主な機能
- 4x4 のアイコンボタン
- 10ページ保存
- ページ送りキー、ページ戻りキーを設定可能
- 各ボタンにショートカットキーと実行コマンドを設定可能
- FF14の/acや/hotbarなどのチャットコマンドを実行可能
- /で始まらない行は通常チャット本文として送信可能
- PNG/JPG/WEBPなどの画像をアイコンとして選択可能
- アイコンサイズ、ボタン間隔、背景アルファを調整可能

アイコンについて
このプラグイン本体にはFF14公式アイコン画像は同梱していません。
別途アイコン抽出プラグインなどで icons フォルダを作成し、
設定画面の「アイコンフォルダ」に指定してください。

実行コマンド欄について
/で始まる行はFF14/Dalamudコマンドとして送信します。
/で始まらない行は通常チャット本文として送信します。

例:
/p よろしくお願いします
よろしくお願いします

注意
FF14、XIVLauncher、Dalamudの利用規約やプラグイン利用ポリシーを確認し、
自己責任で使用してください。
